# Rådgiverassistenten

Intern demo av hvordan AI kan støtte salg og rådgivning hos ODIN Forvaltning. Siden har fire eksempler:

1. Oppfølgingsmail etter et kundemøte
2. Fondssammenligning med risikomål
3. Markedsoppdatering fra forvalterkommentarene
4. Porteføljesimulering for institusjonelle kunder

Hele demoen ligger i én fil, `index.html`, uten byggesteg.

## Data

- Tallene gjelder per 30.09.2026, og hver tabell oppgir kilde og dato.
- Egne fond er hentet fra faktaark, fondssider og månedskommentarer på odinfond.no.
- Sammenligningsfondene bygger på Morningstar-data.
- Anslagene fremover bygger på Finans Norges avtale om avkastningsprognoser (revidert 04.02.2026).
- Kundesituasjonene er oppdiktet.
- Sammenligningsfondene er valgt for demoen og bør kvalitetssikres av forvalterne.

## Viktig før deling

- Dette er ikke kundemateriell.
- Morningstar.com oppgir at dataene ikke kan videredistribueres. Repoet bør derfor være privat, og siden bør ikke publiseres åpent før bruken er avklart med Morningstar.
- GitHub Pages på et privat repo krever en betalt GitHub-plan. Ellers kan filen åpnes lokalt i nettleseren.

## Visuell profil

Fargene følger ODINs profil: grønn `#4F6851`, varm off-white `#FEF9F2` og svart. Mørk modus bruker samme tone-i-tone-prinsipp.

ODINs skrifter er ABC Laica og Store Norske Geita, som er lisensbelagte. Siden prøver ABC Laica først og bruker Hanken Grotesk (Google Fonts) som erstatning der skriften ikke er installert.

## Kjøre lokalt

Åpne `index.html` i en nettleser. Skrifttypene lastes fra Google Fonts, så maskinen må være på nett.
